드래곤볼 PC 연구소

드래곤볼 = 예산 안에서 성능이 가장 높은 부품 꿀조합

처음 오셨나요? 3단계면 끝나요

  1. 예산 입력 — 금액을 넣거나 아래 버튼(150만~400만원)을 누르세요.
  2. 꿀조합 담기 — 다나와 최저가로 계산한 조합 중 마음에 드는 것을 ‘이 조합 담기’.
  3. 링크·견적 복사 — ‘내 조합’에서 공유 링크나 견적서를 복사해 보내세요.

예산으로 자동 추천

기본은 일반결제 최저가(배송비 포함)입니다. 일반결제 판매처가 없는 부품은 다나와 표시가를 쓰고 ‘표시가’ 태그를 붙입니다. 용도에 따라 CPU·GPU 비중이 달라지고(FHD 고주사율·방송·작업용은 CPU 비중↑, 작업용은 코어 수·VRAM 가산), 예산 안에서 성능 지수가 가장 높은 조합을 고릅니다.

내 조합

다나와 실시간 검색 🔒

가격표에 없는 부품을 지금 다나와에서 찾아 담을 수 있습니다.

이 배포판에서는 다나와가 서버 접속을 막아 실시간 검색을 쓸 수 없습니다. 위 가격표는 수집된 다나와 가격이고, 실시간 검색은 내 PC에서 start-site.bat을 실행하면 됩니다.

웹 리서치 🔒

벤치마크·비교 글을 찾아 AI가 출처 번호를 붙여 요약합니다.

유튜브 리뷰 🔒

리뷰 영상을 찾고, AI가 영상을 직접 보고 요약합니다.

가격은 조회 시점 다나와 기준이며 바뀔 수 있습니다. 구매 전 판매처에서 다시 확인하세요. 회원 쿠폰·옵션 추가금은 반영되지 않았습니다. 성능 지수는 대략적인 게이밍 티어 값입니다.

🔒 표시 기능(실시간 검색·AI 요약·웹/유튜브 조사)은 사이트 주인의 API를 쓰므로 접근 코드가 필요할 수 있습니다. 가격표와 빌더는 누구나 쓸 수 있습니다.

가격 데이터: 다나와 공개 가격비교 · 수집 도구: k-skill (NomaDamas, MIT) · 웹 조사: Firecrawl · AI 요약: Google Gemini

🔒 접근 코드

다나와 실시간 검색·쇼핑몰별 가격, AI 요약·조합 평가, 웹·유튜브 조사는 사이트 주인의 API 키를 쓰기 때문에 접근 코드가 필요합니다. 가격표와 빌더는 코드 없이 쓸 수 있습니다.
